# Approved landing direction

User selected chooser option C (inline Spaces tree) and the flat, state-grouped Priority list. Refinement: each Priority row shows its space name, or the explicit repository name when the space has no name.

The resulting landing has a small herdr/machine header; top Priority / Spaces tabs; blocked, finished, working, idle and unknown agent groups; and expandable Space → Tab → Pane navigation. Repeated Priority names gain tab context, and tree rows show status in text. Rows open one existing pane. It uses no terminal output or generated summary in the overview.

The choice is represented by `.impeccable/mocks/decision/inline-tree.png` and the Priority list treatment in `.impeccable/mocks/decision/two-tabs.png` in the project workspace. Those comps are design evidence, not shipped raster assets.
